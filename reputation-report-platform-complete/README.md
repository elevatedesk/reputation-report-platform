# The Reputation Report™ Platform

This package keeps the same approved dashboard look from your HTML file and packages it for GitHub and Netlify.

## Upload to GitHub

Upload every file and folder in this ZIP to your GitHub repository.

## Deploy on Netlify

Build command:

```bash
npm run build
```

Publish directory:

```text
public
```

Functions directory:

```text
netlify/functions
```

## What is included

- Approved dashboard look
- EVG branding
- Client/Admin view toggle
- Intake
- Asset Recovery™
- Social Listening + Reviews
- Reputation 360™
- Local save
- Generate report button
- Netlify function starter
- Netlify config

## Note

This version is deployment-ready for Netlify as a front-end operational prototype. Live Google, social listening, reviews, AI, and database features require API keys and a production database.
